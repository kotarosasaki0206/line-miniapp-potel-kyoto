# 梅小路ポテル京都 ご滞在ガイド（非公式デモ）

梅小路ポテル京都を題材とした提案用の体験デモ。公式サービスではありません。館内ガイド、同一サイト内のログイン不要なチャット風予約、モバイルチェックイン、アンケートを試せます。

予約・決済・実際のチェックインは発生しません。チャットの料金と空室、プラン、予約番号は架空のサンプルです。宿泊者情報とアンケート回答はブラウザ内の表示にのみ使い、サーバーに送信・保存しません。チェックインのサンプル番号は `DEMO-POTEL-1001` です。

```sh
npm ci
npm run build
npx wrangler dev
```

画面は `/`、チャット予約は `/booking/`、デモAPIは `/api/chat` です。施設情報の根拠は [SOURCES.md](SOURCES.md) を参照してください。ヒーロー画像は生成したコンセプト画像で、実際のホテルを撮影したものではありません。
